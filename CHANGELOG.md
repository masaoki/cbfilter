## [1.0.3](https://github.com/masaoki/cbfilter/releases/tag/1.0.3) (2025-12-21)

### Features

* New API template for Anthropic.
* Added some screenshots on README.
* The model chosen in the initial setup dialog is set as the model name, not a title like "Text/Text" which is not descriptive.
* Added a checkbox to set as a resident proguram on installer.

### Fixes

* Installer fiexed to records correct version.
* URL parser now accepts port number, like "http://localhost:11434/" of your local Ollama API.

## [1.0.0](https://github.com/masaoki/cbfilter/releases/tag/1.0.0) (2025-11-30)

### Features

* Custom AI Filter for Windows 11 Clipboard.
* Supports both text and image inputs.
* Initial four type filter definitions, i.e. English translation, image generation, transcription, and anime conversion.
* API definitions for OpenAI (compatible), Gemini, and OpenRouter.
* Supports 13 natural languages.
